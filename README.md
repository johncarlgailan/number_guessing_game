# Number Guessing Game

## Description

Lets the user guess a number from 1 to 100 and tells them if they are correct.

## How It Works

The user enters a number, and the program tells them if it is too high or too low. Once the user enters the correct number, the program shows how many attempts have been made.

## Features

- Tells the user if their guess is too high or too low.
- If the user is incorrect, the program repeats until the correct number is entered.
- Tells the user the number of attempts made.

## Technologies

- Python

## Purpose

I built this project mainly to practice loops, if, elif, else statements, and break.
